# Paper Figure Reproduction

This directory contains sample notebooks for reproducing the data and visualizations from the accompanying paper.

## Data Resources

All required data for reproducing the figures can be downloaded from [Zenodo](https://zenodo.org/records/18407547).

## Reproduction Guide

### Figures 1-5 :
1. Open and run `load_paper_data.ipynb`
2. Open the corresponding `figX.ipynb` and specify the data directory which saved the output of `load_paper_data.ipynb`
3. Fully run the notebooks to produce the plots

### Figures 6-12
1. Open and run `final_fig6_15_recreation.ipynb`

### Supplementary Figure S9 (Figure 14):
1. Open and run `subgrid_onset_variability.ipynb`
